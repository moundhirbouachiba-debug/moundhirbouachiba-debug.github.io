1ère Année (SLAM) Pathé Mâcon (Projet / Atelier)

Gestion de Cinéma (Pathé Mâcon)

Développement d'une solution informatique complète pour la gestion des séances de cinéma, incluant une application lourde de back-office C# WinForms et un site web public en PHP/MySQL.

C# WinForms PHP MySQL Visual Studio

🎯 Objectifs

  • ✓ Automatiser la planification des films, des salles et des séances cinéma.
  • ✓ Générer des documents PDF automatisés pour les bilans de diffusion administrative.
  • ✓ Créer une interface web connectée pour la consultation publique des horaires et réservations.

📝 Contexte & Missions

Dans le cadre de l'atelier de spécialité SLAM de 1ère année au Lycée Lamartine, j'ai développé de bout en bout une solution logicielle pour le cinéma Pathé de Mâcon.

La mission s'est déroulée en deux phases clés : la création d'une application C# orientée objet pour les gestionnaires (gestion des films, affectation des salles, génération des grilles horaires) et un site web PHP dynamique pour les clients finaux accédant aux horaires en temps réel.

⚠️ Constat du problème technique rencontré

Gérer la communication asynchrone et les latences entre la base de données distante hébergée sur MySQL et l'application lourde locale C# WinForms en conservant l'intégrité transactionnelle et la fluidité de l'interface utilisateur.

✓ Solution technique apportée

Mise en place d'une couche d'accès aux données (DAL) avec classes unifiées, sécurisation de la chaîne de connexion distante avec chiffrement, utilisation de requêtes paramétrées, exécution en tâches d'arrière-plan (BackgroundWorker / async/await) et gestion stricte des exceptions SQL (MySqlException).

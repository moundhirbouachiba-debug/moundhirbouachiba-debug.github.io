PPE 3/4 : Solution Métier & Web (Brit Hotel)

Projet de synthèse final validant l'ensemble des compétences de deuxième année : plateforme hôtelière complète combinant un logiciel client C# Entity Framework et une application web Laravel.

Laravel C# .NET Entity Framework MySQL PHP PDO Transact-SQL

🎯 Objectifs

  • ✓ Centraliser la gestion des réservations hôtelières et la disponibilité des chambres en temps réel.
  • ✓ Développer un back-office C# avec l'ORM Entity Framework pour les réceptionnistes et la facturation.
  • ✓ Déployer un portail client web sous le framework PHP Laravel avec moteur de template Blade.

📝 Contexte & Missions

Dans le cadre de l'épreuve de synthèse de 2ème année BTS SIO SLAM, j'ai participé à la modernisation intégrale du système d'information de l'hôtel Brit Hotel.

Le projet impliquait l'interfaçage d'une base de données relationnelle MySQL avec deux environnements distincts : une application lourde Windows Forms codée en C# exploitant les fonctionnalités avancées d'Entity Framework (DbContext, mapping relationnel-objet, LINQ to Entities) et une application web responsive sous Laravel 11 offrant un tunnel de réservation fluide aux clients.

⚠️ Constat du problème technique rencontré

Conflits de concurrence d'accès lors de réservations simultanées de la même chambre entre le portail web client Laravel et l'application lourde de réception C#, risquant d'aboutir à un surbooking (double réservation).

✓ Solution technique apportée

Mise en place de transactions SQL avec niveau d'isolation sérialisable (ACID), intégration d'un token d'accès concurrentiel (ConcurrencyCheck / RowVersion) dans Entity Framework et mise en place d'un verrou optimiste avec contrôle strict des dates via une procédure stockée commune aux deux applications.
